=== Conclusion ===
Flash encryption ENABLED, RELEASE mode. read_flash over the bridge returns the same ciphertext
already in update.fpkg. DISABLE_DL_CACHE blocks the cache-remap trick; the key is read-protected;
silicon v3.1 has no public glitch key-extraction. The plaintext ESP32 firmware is NOT recoverable
from this device. This is the release-mode branch (step 4) of docs/ESP32.md, confirmed on hardware.
